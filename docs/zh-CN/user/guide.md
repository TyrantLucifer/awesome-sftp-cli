# 使用指南

[English](../../user/guide.md)

本指南介绍 AMSFTP 的日常用法：连接 SSH 主机、双栏浏览、执行可续传后台传输，以及
预览、编辑和搜索远端文件。完整配置项、快捷键列表与命令行参数请见
[配置与命令参考](reference.md)。

## 1. 连接与启动

AMSFTP 将所有 SSH 配置、认证与主机密钥校验完全交给系统 OpenSSH（`/usr/bin/ssh`）。

1. 在 `~/.ssh/config` 中配置一个明确的主机别名（带通配符的 `Host *` 不会出现在
   服务器列表中）：

   ```sshconfig
   Host work
       HostName dev.example.com
       User alice
       IdentityFile ~/.ssh/id_ed25519
   ```

   系统已有的 `ssh-agent`、`ProxyJump`、`ProxyCommand`、MFA 交互认证以及
   Kerberos/GSSAPI 都可以直接使用。

2. 先用系统 OpenSSH 登录一次确认主机密钥和认证，再用 `doctor` 做检查：

   ```sh
   /usr/bin/ssh work
   amsftp daemon start
   amsftp doctor --endpoint work
   ```

   `doctor` 只做只读检查，不会修改任何文件或 SSH 信任记录。

3. 启动 AMSFTP（可传入 0、1 或 2 个位置）：

   ```sh
   amsftp                                           # 打开启动选择器
   amsftp /local/dir                                # 打开一个本地目录
   amsftp /local/dir work:/srv/project              # 左栏本地 + 右栏远端
   amsftp host-a:/data host-b:/backup               # 双远端主机
   amsftp --workspace project                       # 打开已保存的工作区
   ```

   本地和远端路径都必须是绝对路径（`/local/path` 或 `<ssh-alias>:/remote/path`）。

### 保存工作区

按 `S` 可保存当前双栏布局（左右路径、当前焦点栏、排序与过滤方式、是否显示隐藏
文件以及缓存策略）。工作区只记录 SSH 主机别名，绝不保存密码、私钥或票据。之后可
通过 `amsftp --workspace <name>` 或启动选择器一键恢复。

## 2. 浏览、选择与终端操作

界面包含左右两个独立文件栏，高亮的一栏为当前操作栏。

- **移动与浏览：** `h`/`j`/`k`/`l`（或方向键）移动与进入目录；`gg` / `G` 跳到
  已加载列表首尾；`g` 输入绝对路径跳转；`/` 在当前目录内模糊跳转；`s` 切换排序；
  `H` 切换隐藏文件；`R` 刷新。安全的移动按键支持数字前缀（例如 `12j` 向下 12 项）。
- **切换栏与主机：** `Tab` 切换左右栏；`c` 打开主机选择器（包含 `local` 和
  `~/.ssh/config` 中的具体别名）切换当前栏。如果新主机连接失败，原文件栏保持不变。
- **选择文件：** `Space` 单项勾选，`v`/`V` 进入框选/行选，`Esc` 取消选择或关闭
  最内层弹窗。未选中任何条目时，操作默认针对光标所在项。
- **底部面板：** `K` 预览、`J` 后台任务、`L` 脱敏诊断日志。面板聚焦时再按一次
  相同按键即可关闭；按 `Esc` 把焦点退回文件栏。
- **独立重连：** 左右两栏各自维护独立 SSH 会话。一台服务器断线时，另一栏仍可正常
  操作。重连后若原目录已被删，AMSFTP 会自动退回到最近的可访问上级目录并给出提示。
- **运行命令与交互 Shell：** 按 `!` 在当前目录执行一条经二次确认的命令；按 `gs`
  在当前目录打开交互 Shell；远端目录无法进入时按 `gS` 打开远端 home 目录 Shell。
  远端 Shell 使用全新 SSH 连接且关闭 Agent Forwarding。Shell 内执行的命令直接
  使用当前账号权限，不受 AMSFTP 传输确认机制保护。
- **安全退出：** 按 `q` 或 `Ctrl-C` 退出 TUI，后台传输任务会继续在 daemon 中运行。

## 3. 复制、移动、重命名与删除

所有文件变更操作都以持久化后台任务（Job）的方式交由本地 daemon 执行，不依赖 TUI
进程存活。

### 复制与移动

1. 选中文件（`Space`、`v`、`V`）或将光标停在目标条目上。
2. 按 `y` 复制，或按 `d` 剪切（小写 `d` **永远不会**直接删除文件）。
3. 按 `Tab` 切换到目标栏，按 `p` 粘贴。
4. 核对来源、目标、条目数与冲突处理方式后确认，按 `J` 查看任务进度。

**安全保证：**

- **不产生写了一半的残缺文件：** 数据先写入任务专属临时文件，全部完成后才重命名为
  正式文件名。
- **移动先保底再删源：** 当无法使用同主机安全重命名时，移动操作会先完成复制、校验
  并正式重命名到位，再去复核并删除源文件。若无法确认源文件是否删除成功，AMSFTP 会
  保留源文件并将任务标记为“已完成但保留源文件”，方便你核对两边后再处理。
- **不跟随符号链接：** 递归复制或删除目录时，符号链接按链接本身处理，不会顺着链接
  跨出目录树。
- **远端到远端复制：** 两台 SSH 服务器之间复制时，数据通过本地 daemon 按小块内存
  流式转发——既不会把整份文件落盘到本地预览缓存，也不会把 SSH 凭据复制到服务器。

### 重命名与删除

- **重命名（`r`）：** 仅针对光标所在的单个文件或目录，不支持多选。
- **删除（`D`）：** 大写 `D` 是唯一删除快捷键。因为标准 SFTP 没有回收站（本地模式也
  直接永久删除），删除前默认需要两次确认（核对目标清单 + 确认不可逆删除）。根目录
  或发生并发变化的目标会被直接拒绝。

### 冲突处理与任务控制

目标已存在时，可选择 **覆盖**（覆盖前先核对目标未发生二次变化）、**跳过**、
**自动重命名** 或 **询问**（暂停任务等待决定）。

在任务面板（`J`）中用 `j`/`k` 选择任务：

- **控制：** `P` 暂停、`U` 继续/重试、`C` 取消。
- **处理冲突：** `w` 覆盖、`x` 跳过、`a` 自动重命名；大写 `W`/`X`/`A` 将对应选择
  应用到同一任务内的后续匹配冲突（不会变成全局默认）。

常见任务状态：

- **排队 / 运行 / 校验中：** 等待调度、正在传输或正在校验数据。
- **等待认证：** 先用 OpenSSH 续期登录、Agent 或 Kerberos 票据，再按 `U` 继续。
- **等待冲突：** 在任务面板里按 `w`/`x`/`a` 做出选择。
- **已暂停 / 等待重试：** 进度已持久保存，准备好后按 `U` 继续。
- **已完成但保留源文件：** 目标已校验完成，但未能确认源文件删除，请手动核对两边。

也可在命令行使用 `amsftp job list|events|pause|resume|cancel` 管理任务。

### 校验、落盘同步与断点续传

普通复制可通过两项独立配置在速度与严格度之间权衡（详见[参考手册](reference.md)）：

- **默认复制（`verification: "protocol"`，`durability: "none"`）：** 要求所有 SFTP
  写入均收到服务端确认、字节数完全匹配、文件正常关闭、临时文件重命名成功。成功路径
  不回读目标，也不强制 `fsync`。
- **内容校验（`verification: "sha256"`）：** 回读并计算临时文件与正式文件的 SHA-256
  摘要（上传时会增加 2 倍读 I/O）。
- **落盘同步（`durability: "completion"` 或 `"checkpoint"`）：** 在重命名前调用一次
  `fsync`（`completion`，类似 `sftp put -f`），或在每个检查点（约每 64 MiB 或 5 秒）
  调用 `fsync`（`checkpoint`）。

移动操作与远端编辑回写始终保留更严格的 SHA-256 校验与检查点同步。

传输中断或 daemon 重启后，AMSFTP 不会盲目追加或截断。续传前会对照已保存的源文件
摘要校验临时文件；如果最后一步重命名响应丢失，即使在默认模式下也会先完成全量内容
校验才认作成功。若现场存在歧义，任务会明确暂停或报冲突，绝不靠猜。

## 4. 预览、编辑、打开与搜索

### 预览文件

在文件上按 `K`（或直接按 `l`）打开预览。用 `j`/`k` 滚动，用 `h`/`l` 或 `gg`/`G`
查看大文件的头部/尾部范围，按 `r` 在自动视图、原始 JSON 与元数据视图之间切换。

预览按小范围分段读取而不下载整个文件，会转义不安全的终端控制字符；符号链接仅展示
元数据；图片仅在终端主动证实支持图片协议时才渲染。

### 本地编辑与外部打开

- **编辑（`e`）：** 下载临时副本到私有缓存、确认编辑器命令、交出终端并等待编辑器
  退出。编辑器查找顺序：`config.json` 中的 `external.editor` → `VISUAL` → `EDITOR`
  → `PATH` 中的 `nvim` / `vim` / `vi`。
- **外部打开（`o`）：** 用 `/usr/bin/open`（macOS）、`/usr/bin/xdg-open`（Linux）或
  `external.opener` 打开缓存副本。因为桌面程序往往立刻返回，AMSFTP 不会在打开命令
  退出时自动上传——编辑完成后按 `Enter` 检查变更，或按 `Esc` 保留会话以便稍后处理。

任何回写上传前，AMSFTP 都会做三方比对（打开时的原始版本 vs 本地修改 vs 远端现状）：

| 本地副本 | 远端文件 | AMSFTP 提供的操作 |
| --- | --- | --- |
| 未改动 | 未改动 | 直接结束（不创建任务） |
| 已改动 | 未改动 | 上传、另存为、跳过或保留待恢复 |
| 未改动 | 已改动 | 仅刷新远端内容（不上传） |
| 已改动 | 已改动/删除 | 提示冲突：明确覆盖、另存为、跳过或保留 |

编辑回写覆盖远端文件前，AMSFTP 会先在同目录保存一份远端原文件的隐藏备份。
若上传中断，按大写 `E` 打开编辑恢复界面，检查或继续未完成的编辑。

### 搜索文件名与内容

| 快捷键 | 行为 |
| --- | --- |
| `/` | 在当前目录已加载的条目中模糊跳转 |
| `f` | 在当前目录下递归搜索文件名 |
| `g/` | 在当前目录下递归搜索文件内容（SFTP 下会先弹窗确认；默认跳过二进制文件） |

递归搜索对深度、条目数、字节数、耗时和结果数都设有硬上限。触发上限时会返回已找到
的匹配并明确标记为**部分结果**。你可以直接对搜索结果执行打开、预览或复制操作。

### 本地缓存策略

预览、编辑与外部打开共用按工作区管理的本地缓存（默认上限：全局 2 GiB、单工作区
1 GiB）。正在被预览、编辑器、外部程序或待恢复会话使用的文件会被锁定，不会被自动清理。

当 `g` 路径输入框为空时：

- 按 `gp` 切换当前工作区的缓存策略：**自动**（`lru`，默认）→ **临时**（`ephemeral`）
  → **离线**（`pinned_offline`，保留副本供离线查看，但上传前仍需连回服务器复核）。
- 按 `gc` / `gC` 预览并清理当前工作区 / 全部工作区的可回收缓存。

按 `S` 可将该策略随工作区一并保存。
